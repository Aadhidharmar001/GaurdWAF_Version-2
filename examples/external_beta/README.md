# GuardWAF External Beta Starter Kit

Welcome! This is the starter project for external developers testing GuardWAF.

---

## 🚀 Quickstart Instructions

1. Install GuardWAF:
   ```bash
   pip install guardwaf
   ```
2. Run the starter project:
   ```bash
   python main.py
   ```

---

## 📁 File Structure
- `main.py`: Minimal Python script demonstrating `@protect` decorator, allowed action, HITL action, and policy blocked action.
- `policy.yaml`: Declarative policy configuration setting bulk threshold limits and HITL rules.

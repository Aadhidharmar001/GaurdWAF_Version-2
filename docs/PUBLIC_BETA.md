# GuardWAF Public Beta Program Guide

Welcome to the GuardWAF Public Beta Program!

---

## 🎯 Program Goals

GuardWAF is now in **Public Beta**. We are gathering feedback from AI developers building production AI agents to refine developer experience, integration adapters, and policy syntax.

---

## 📋 Feedback Areas

1. **Installation & Onboarding**:
   - Was `pip install guardwaf` smooth?
   - Did the 60-second quickstart work as expected?
   - Did you reach your first protected tool in **< 10 minutes**?

2. **Framework Integrations**:
   - Are you using LangChain, LangGraph, CrewAI, FastMCP, or custom agent loops?
   - Were integration adapters intuitive?

3. **Policy Rules & HITL**:
   - Was policy YAML clear?
   - Did Human-in-the-Loop approval tokens work seamlessly?

---

## 💬 How to Provide Feedback
- Submit a [GitHub Issue](https://github.com/aadhidharmar001/guardwaf/issues) using our issue templates.
- Join our [GitHub Discussions](https://github.com/aadhidharmar001/guardwaf/discussions).
- Send confidential security feedback to `security@guardwaf.io`.

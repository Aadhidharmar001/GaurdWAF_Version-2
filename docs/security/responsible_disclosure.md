# GuardWAF Responsible Disclosure Policy

Security is central to GuardWAF's mission as an Agent Action Authorization & Runtime Governance Platform.

## Reporting a Vulnerability
- Please email security reports to `security@guardwaf.io`.
- Include reproducible details, environment info, and sample payload.
- We acknowledge reports within 24 hours.
- We request that security researchers maintain confidentiality until a patch is issued.
